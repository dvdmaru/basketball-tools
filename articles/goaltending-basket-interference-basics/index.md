# 那球到底吹哪一種？NBA 規則書把「妨礙中籃」和「干擾球」寫進同一份清單裡

**新手村｜規則入門・妨礙中籃與干擾球**

同樣是伸手碰球，結果可以相反。

防守球員碰到一顆仍有機會進框的下降球，進攻方可能直接拿到分數；進攻球員在自己籃框碰到同樣受保護的球，得分則可能被取消。這不是裁判在替「動作比較危險」的一邊加重處罰，而是 NBA Rule 11 先看球的狀態，再看違規發生在哪一個籃框。

## 先看球：有些球還不能碰

Rule 11 列出九種球員不得做的事。最常出現在轉播回放的幾種，是碰到籃框上方、位於假想圓柱體內的球；碰到已打到籃板、且接觸點在籃框高度以上、仍有機會進框的球；以及碰到下降中、仍有機會進框的球。

最後一種很容易被簡化成「球下來就不能碰」，但條文同時要求下降飛行和有機會進框。球的飛行方向只是其中一個條件。

還有一些情況根本不用等球下降：手從籃框穿過去碰球、把球夾在籃板上、在球碰框或穿網時搖動籃框與籃板、球還在網裡就碰球或籃框，Rule 11 都列為違規。這些畫面看起來不完全相同，規則書卻把它們放在同一份清單裡。

## 再看籃框：在哪一邊違規，決定分數怎麼算

Rule 11 的罰則不先說「進攻」或「防守」，而是問違規發生在哪一邊籃框。

- 在對方籃框違規：未犯規方獲得該次投籃應有的 2 分或 3 分。
- 在自己籃框違規：不計分，球權交給對方，從罰球線延伸處附近發球。
- 雙方都違規：不計分，改由中圈跳球重新開始。

這就是為什麼防守違規判得分，進攻違規判取消：防守方碰到對手的受保護球，常看起來像「直接送分」；進攻方碰到自己隊正要進的球，則像「自己把分數撥掉」。名稱可以幫助轉播溝通，但真正決定結果的是 Rule 11 的位置與罰則。

## 「妨礙中籃」和「干擾球」不是兩條互不相干的規則

球迷常把下降中的球稱作妨礙中籃（goaltending），把籃框、籃網附近的碰球稱作干擾球（basket interference）。NBA 規則書當然會使用這兩個英文詞，但在 Rule 11 的核心條文裡，它沒有先把九種禁止動作分成兩個互斥的標籤，而是把判斷條件逐項列出。

因此，遇到爭議畫面，比起急著替它貼名詞，更有用的順序是：球當時在哪裡？是否仍符合條文保護的狀態？違規發生在哪一邊籃框？三個問題能直接連到處理結果。

## 不要只看「有沒有碰到籃框」

灌籃或補籃時，球員的手可能接觸籃框；這件事本身不會自動回答 Rule 11 的問題。規則所列的是特定時點與特定影響，例如球坐在籃框上、球穿網時阻止它清出籃框，或搖動籃框造成球不自然彈跳。

同樣地，碰到籃板也不是一律違規。條文關心的是球是否已進入列出的狀態，以及觸球怎麼改變了那一球。把畫面拆成球的位置、飛行與接觸方式，會比只看手有沒有碰到框板準確。

## 常見問題

### 球下降時碰到，一定是妨礙中籃嗎？

不一定。NBA Rule 11 對其中一種情況的條件是：球在下降飛行中，而且仍有機會進框。只看「下降」不足以完成判斷；其他接觸籃框附近球的情況，也各有自己的條件。

### 為什麼防守方違規會直接判得分？

Rule 11 規定，若違規發生在對方籃框，未犯規方獲得該次投籃應有的 2 分或 3 分。規則以違規發生在哪一邊籃框決定結果，而不是先以進攻或防守的名稱分類。

### 進攻方干擾球，會怎麼判？

若違規發生在自己籃框，Rule 11 規定不計分，球權交給對方，從罰球線延伸處附近發球。不是每次碰框或碰網都自動構成違規，仍要先符合條文列出的情況。

### NBA 規則把妨礙中籃和干擾球分開寫嗎？

Rule 11 的核心段落以九種禁止動作合併列舉，罰則也統稱為違規。閱讀爭議畫面時，先把焦點放在球的位置、飛行與違規發生的籃框，通常比先替它貼名詞更能回答結果。
