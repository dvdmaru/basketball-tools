# NBA 換人不是哨響就能上：先報到，等裁判招手，再看比賽停在哪

**新手村｜規則入門・換人**

電視畫面裡，替補走到記錄台旁、喇叭響起，接著才有裁判招手。這一連串動作不是儀式，而是 NBA Rule 3 對換人的基本程序。

最容易誤會的是「只要死球就能換」。死球確實常是換人的入口，但 Rule 3 還分別處理進球後、罰球、裁判暫停比賽，以及剛換上場又想立刻換下的情況。要讀懂一次換人，先看程序，再看比賽停在哪一種情境。

## 站到記錄台旁，不等於已經進場

替補要先向記錄員報到，站在記錄台前方的換人區附近，並告知要替換哪一名球員；記錄員再以喇叭示意換人。節間或暫停期間換人時，不需要鳴喇叭。

但替補仍必須在換人區附近等待裁判招手。若球即將成為活球，裁判會暫緩招手。這就是為什麼鏡頭裡已經看到球員站在場邊，卻不代表他能在下一秒直接跑進場。

Rule 3 對「已在比賽中」也寫得很明確：裁判招手讓替補進場，或裁判認定他已在場上比賽時，才算正式入場。

## 投進球後，原則上不能直接換人

任一隊投進球後，Rule 3 的原則是替補不得進場。這能避免得分後的端線發球被任意拖延。

不過條文也列出例外：若球因個人犯規、技術犯規、暫停、感染控制，或違例而成為死球，才可以換人。因此，看到得分後出現換人，問題不是「進球後能不能換」，而是接下來是否又出現 Rule 3 列出的死球原因。

暫停是很直觀的一個例外。Rule 5 另規定，暫停期間兩隊換人都合法；所以同樣是得分後，是否獲准暫停會改變結果。

## 罰球與裁判暫停比賽，各有自己的門檻

判罰球時，替補一般只能在末一罰出手前進場——前提是球會維持活球；若末一罰後球不會維持活球，則要等到末一罰出手後。取消資格、受傷、驅逐等非典型情況，條文另列例外。

裁判為延誤比賽警告、撿回失控球、誤鳴哨、即時重播檢視等原因暫停比賽時，替補原則上也不能進場。球員流血，或嚴重受傷且必須離場，是 Rule 3 明列的例外。

因此，「裁判吹哨停表」不是一個足夠的換人判斷。還得知道哨聲究竟是犯規、暫停、罰球程序，還是裁判暫時中止比賽。

## 剛被換上，也不能想換就立刻換下

替補一旦被裁判招手進場，在場上球員合法觸球前，原則上不能再被換下。Rule 3 列了四個例外：個人或技術犯規、球權改變、准許暫停，或執行感染控制規則。

同一死球期間，被換下的球員可以再以替補身分回到比賽；但剛換上的球員仍受前一段的限制。這兩句要一起讀，才不會把「可以回場」誤解成任何人都能無限制地來回換。

## 常見問題

### 替補已經站在記錄台旁，為什麼還不能上？

站在換人區附近、向記錄員報到只是程序的一部分。依 Rule 3，替補還要等裁判招手；若球即將成為活球，裁判會暫緩招手。

### NBA 進球後可以直接換人嗎？

原則上不可以。Rule 3 規定任一隊投進球後，替補不得進場；若之後因個人犯規、技術犯規、暫停、感染控制或違例而成死球，才是條文列出的例外。

### 罰球時什麼時候可以換人？

Rule 3 的一般時點是：若球會維持活球，替補可在末一罰出手前進場；若末一罰後球不會維持活球，則在末一罰出手後進場。取消資格、受傷或驅逐等非典型情況另有例外。

### 剛換上場的球員，可以馬上又換下嗎？

原則上不行。替補被裁判招手進場後，要等場上球員合法觸球，才可以再換下；個人或技術犯規、球權改變、准許暫停與感染控制是 Rule 3 列出的例外。
