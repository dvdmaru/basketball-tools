# TPBL、PLG 官方數據頁怎麼看？先分清基本表、排行與外部進階資料

**新手村｜台灣職籃・從官方公開頁讀數據**

看到「球員數據」四個字，不代表兩個聯盟會用同一張表、同一組欄位，或在同一時間提供相同深度的資料。讀 TPBL、P. LEAGUE+（PLG）官方頁面時，第一步不是急著找一個指標的公式，而是先確認：你開的是球員表、排行頁、球隊表，還是另一個外部資料產品？

這篇只處理讀者公開可見的入口與欄位。它不替聯盟補定義，也不把頁面程式裡未以讀者介面公開的字串，當成一項已公告的統計公式。

## TPBL：先選資料類型與賽季，再確認頁面是否已有可讀的列

TPBL 官方的「比賽數據」區有球員數據、球隊數據、數據排行、特殊表現與歷史紀錄等入口。球員數據頁可搜尋球員，並可選 2026-27 賽季；公開頁面還列出「一般數據」「得分」「場均數據」等選項。

不過，截至本文查核日，這個公開頁面回傳「篩選下沒有任何資料」。這不等於聯盟沒有記錄比賽，而是這個讀取時點的公開頁面沒有提供可直接逐列核對的球員表。因此，遇到空表時最穩妥的寫法是記下頁面的資料類型與查核日，不從空白表推論球員排行、場均或進階指標。

TPBL 的球隊數據頁同樣保留賽季、勝率與場均數據等篩選入口，查核時也顯示沒有資料。若之後頁面出現資料列，讀法仍應先看清楚篩選的是哪一季、哪一類數據，以及數字是總計還是場均。

## PLG：公開球員表先給基本欄位，數據排行則把類別拆開

PLG 的 2026-27 球員數據公開頁已經有資料列。表頭依序能讀到出賽（GP）、時間（MIN）、得分（PTS）、二分與三分命中／出手／命中率、罰球命中／出手／命中率、籃板（REB）、進攻籃板（OREB）、防守籃板（DREB）、助攻（AST）、阻攻（BLK）、抄截（STL）、失誤（TO）與犯規（PF）。

這些欄位適合回答「這名球員累積了什麼基本產出」；但它們並不是互相可以單獨比較的分數。例如得分要搭配出賽與時間看，命中率至少要連同出手量看，籃板也可先拆成進攻與防守籃板。只看一個欄位，通常不足以判定球員整體影響力。

同一個 PLG 網站的綜合排行頁，則把得分、籃板、助攻等項目分開列成排行。排行頁適合快速找出該項目的當前領先者；若要核對某個人的完整基本數據，再回到球員數據表會比較完整。兩種頁面用途不同，不能把排行頁的單項數字讀成完整球員評價。

## 「進階數據」是入口名稱，不保證公開頁有同一套欄位

PLG 導覽把球員數據標為「基本、進階」，而官方導向的 STATZONE 產品頁則寫有即時比分、逐場進階數據與歷年球季紀錄，並區分公開畫面與帳號升級後的完整資料庫。這說明進階資料存在不同的產品層次，但不代表主站公開球員表已完整列出所有進階欄位，也不代表讀者可以從主站基本表反推出外部平台的算法。

因此，碰到 EFF、+/- 或其他縮寫時，建議先問三件事：

1. 該縮寫是否真的出現在你正在看的公開表頭或說明頁？
2. 這個頁面是否同時公開了定義與計算方式？
3. 該數字是單場、賽季累積還是場均，篩選條件又是什麼？

三題中任何一題沒有答案，就把它當成「目前頁面資訊不足」，而不是用其他聯盟的慣例去補。

## 基本表的實用讀法：先把成對欄位放在一起

| 想知道什麼 | 至少一起看哪些欄位 | 不應直接推出的結論 |
|---|---|---|
| 出手效率 | 二分／三分／罰球的命中、出手與命中率 | 只靠命中率判定效率高低 |
| 上場負荷 | GP、MIN 與場均或累積標示 | 把累積得分直接當成每場表現 |
| 籃板來源 | REB、OREB、DREB | 把總籃板視為同一種貢獻 |
| 控球與組織 | AST、TO，以及實際出賽樣本 | 只靠助攻數判定失誤風險 |

同樣的原則也適用於本站的[技術統計表入門](/articles/read-box-score/)。它教的是怎麼讀一張基本 box score；這篇則把焦點放在「先辨認官方頁面現在提供了哪種表」。

## 常見問題

### TPBL 官網現在可以直接查 2026-27 球員排行榜嗎？

TPBL 官網有球員數據與數據排行入口，球員頁也可選 2026-27 賽季；但截至本文查核日，公開球員頁顯示「篩選下沒有任何資料」。因此本文不列任何 TPBL 2026-27 球員排行，之後應以頁面實際出現的資料列與篩選條件為準。

### PLG 的 PTS、REB、AST 是什麼？

在 PLG 公開球員表裡，PTS 是得分、REB 是籃板、AST 是助攻。它們都是基本統計欄位；讀取時仍應配合出賽與上場時間，避免把不同樣本量的累積數字直接相互比較。

### PLG 網站寫有進階數據，是否代表所有進階公式都公開？

不能這樣推論。主站導覽與 STATZONE 產品頁都提到進階資料，但公開球員表和外部產品頁不是同一張表。本文只採公開可見的欄位與產品說明；若某指標沒有在公開頁同時給出定義與公式，就不替它套用其他聯盟的算法。

### 為什麼本文不直接比較 TPBL 與 PLG 哪個數據比較完整？

因為兩邊頁面的資料呈現會隨賽季與公開權限變動。本文查核時，PLG 公開球員表已有資料列，TPBL 的公開球員頁則回傳空表；這只能描述當下公開介面的狀態，不能推論哪個聯盟長期一定提供較多資料。
